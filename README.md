# Tydl

Tydl (pronounced tidal) lets you be intentional about your phone usage and helps accomplish your tasks and record your day in your own words.

It works by simply asking you for a Reason & Time when you open your app.

In addition, you can connect it to your Obsidian vault to keep track of tasks, automatically mark them completed, track your sleep and daily stats, etc 

It's simple and doesn't make you do stuff, but rather works by reminding of your own promises, helping keep you accountable and intentional about choices, whatever those choices may be

## Installation

### F-droid (recommended)

1. Install [F-Droid](https://f-droid.org/), if you do not have it already.
2. Open F-Droid. Go to **Settings → Repositories** and add this repository URL:

   ```
   https://serabin1.github.io/tydl/repo?fingerprint=18AF7DFBE3DC55E16B52F201AF137860E9F23DB0519F458D51F980A2B91A6A1C
   ```

   The `fingerprint` value is the SHA-256 hash of the repository signing key. You can check it on [the repository page](https://serabin1.github.io/tydl/repo). That page also shows a QR code. You can scan the code instead of typing the URL.

3. Search for **Tydl** and install it. F-Droid delivers all later updates.

### GitHub Releases

1. Download the newest `tydl *.apk` file from [GitHub Releases](https://github.com/SerAbin1/tydl/releases).
2. Open the file to install it. If your device asks for it, allow installation from unknown sources.

The F-Droid repository and the GitHub releases use the same signing key. You can switch between them without uninstalling the app.
